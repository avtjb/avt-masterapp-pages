Adding rooms and naming them

How a room is named in LBG Room Checker, and how to add one on the website. Get the name right and the equipment import finds the room by itself.

Who this is forEstate managers. Adding, renaming and deleting rooms is only available to the Estate Manager group on the Room Checker website.

The naming pattern

Standard

Every room is named in four parts, in this order, with a space-dash-space between them.

The pattern, with a real room
1. Type2. Site3. Building4. Room
$MTRANDKeens HouseR01-01
What kind of roomWhich city or siteWhich buildingFloor and room number
Written out in full$MTR - AND - Keens House - R01-01. The first three parts on their own, $MTR - AND - Keens House, name the building; the fourth part says which room in it.
Why the exact name mattersThe name is the room's identity everywhere. When you upload the equipment export on the Import tab, each row's Display name is matched to a room by this name. If the room is called something slightly different, the row comes up as unmatched and someone has to pick the room by hand. The room's code (used on checks and faults) is also worked out from the name.

A few branch sites use their own name instead of a code, for example Poole, Woking, Gravesend and Oxford Street. A brand-new city: use a short code the same way (three letters is the pattern), and tell the people who set up the devices what you chose, so the device's display name uses the same code.

3. Building: the short building name

The building as it appears in the device's display name: Keens House, 33 OBS (33 Old Broad Street), CITYMARK, PEX. Most names write it in capitals and some in normal case; either matches, because capitals are ignored when matching. The Building box on the form is different: that holds the building's full, tidy name (for example Princess Exchange).

4. Room: the floor and room number

For ordinary meeting rooms: the letter R, the floor as two digits, a dash and the room number as two digits. R01-01 is floor 1, room 01. R05-13 is floor 5, room 13. The floor number inside this part is how the app works out the floor. Rooms that do not fit that shape exist (for example R-PE - 00-03 or Research Lab): copy the device's display name exactly and fill in the Floor box yourself.

Hubs have an extra floor partA Surface Hub is named $HUB - EDI - SHN - 0 - Hub 2: type, site, building, then the floor (0), then the hub number. Hubs move around, so their Floor in the app is MOBILE.

Adding a room

Use this when a room exists that is not on the website yet and you are adding it by hand.

  1. Find the buildingOn the Overview tab, find the site and the building the room belongs in. If the building is not there yet, do the next section first.
  2. Press + Add RoomThe button is inside that building's section, so the Site and Building are already filled in.
  3. Type the Room nameThe whole name, all four parts, exactly as the device calls itself: $MTR - AND - Keens House - R01-01. The box shows "e.g. Boardroom 3" as a placeholder, but do not use a plain name like that for a real room: it will never match an import.
  4. Choose the FloorFor example 1. Leave it blank if you do not know yet. Use MOBILE for a hub.
  5. Choose the Room typeMTR, GEC, GEC with IPTV, IPTV, Event Space, Research Labs, SHUB, XL, Working Café or Other. This decides the inspection checklist.
  6. Choose how often it is checkedEvery Working Day, Twice Per Week, Weekly, Fortnight, Monthly, Quarterly, Yearly or Never (for a room on a "next day fix" contract with no regular checks).
  7. SaveThe room appears in the building straight away.
The room code is made for youThe code is the name tidied up: the $ is dropped, capital letters, and spaces and symbols become single dashes. $MTR - AND - Keens House - R01-01 becomes MTR-AND-KEENS-HOUSE-R01-01. Two rooms cannot share a name, so use the full four-part name every time.
Another way: from the equipment import

If you upload the equipment export on the Import tab and a row names a room that does not exist yet, the tab can propose creating it. It works the site, building, room type and a guess at the floor out from the name, and shows them to you to check before anything is written. A created room cannot be undone from that tab, so check the proposal carefully.

A new building or a new site

  1. New building in an existing sitePress + Add Building, pick the existing site, and type the building's name.
  2. New site (a new city)Press + Add City and type the new site's name.
  3. Rename the placeholder roomA building cannot exist with no rooms, so the website creates one placeholder room called <Building name> - New Room (room type Other). Open it, press Edit Room Details and give it the real four-part name, or add the real rooms with + Add Room and delete the placeholder.

Fixing a name

  1. Open the roomFind it on the Overview tab and click it.
  2. Press Edit Room DetailsChange the name (and the type, check frequency, access notes or lease details if needed) and save.
Renaming is safeThe room's code follows the new name, and the code on its past checks and faults is updated with it, so the history stays attached to the room.

FAQ

Where do I find the device's display name?

It is the Display name column in the equipment export you upload on the Import tab. Copy it from there.

The import says a row is "unmatched". What do I do?

Either the room does not exist yet (add it as above, or let the import propose creating it), or its name differs from the device's display name. Compare the two character by character, then fix the room's name with Edit Room Details.

Can I use a name that does not follow the pattern?

Yes, the website accepts any name, and test rooms use plain names. But a real room with a different name will not be found by the import, so stick to the pattern for every real room.

Can I delete a room I added by mistake?

Yes. Deactivate it first, then delete it from the deactivated rooms list. See "Deactivate, reactivate or delete a room" in the Help tab.
