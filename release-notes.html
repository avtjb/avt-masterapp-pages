Release Notes

What's New

A quick, plain-English log of what's changed in the app over time — newest first. For step-by-step help, see the Full App Guide.

21 Sep 2026
  • LBG - Room CheckerThe daily, weekly and monthly report e-mails, and their attached files, briefly carried a "(Dataverse)" tag in the subject line and file name while the old and new systems ran side by side. Now that every site has moved over, that tag has been removed — subjects and file names read exactly as they always did.
  • LBG - Site ManagementNew, managers only: a room can now be added directly from the Overview page with the new + Add Room button on each site, instead of needing a spreadsheet import for a single new room.
  • LBG - Site ManagementEditing a room's equipment: camera, display and touch panel models, the audio system type, and the PC's type and model are now picked from the same list every time, instead of free text anyone could type anything into. A room whose PC had never been recorded before can now have one added, too.
  • LBG - Site ManagementEditing a room's equipment now opens in a large window in the middle of the screen instead of the cramped side panel, with more room to work in. A device marked "N/A" (confirmed not present) no longer clutters the Overview — it's treated the same as a slot nobody's recorded anything for.
  • LBG - Room CheckerNext TestFlight build, Dataverse tile: an Event Space room's Photos page can now capture extra "kit" photos beyond the usual six, tagged by what they show (Cameras, Ceiling Mics, Displays, Racks, Touch Panels, Radio Mics) with no limit on how many. Only shown for Event Space rooms; nothing changes for any other room type.
20 Sep 2026
  • LBG - Room CheckerThe daily, weekly and monthly reports, and the overdue-room alert, now show each room's type. Each site's report table is split into one section per room type instead of one long list — for example, a site's Event Space rooms are now grouped separately from its meeting rooms — and the overdue-room alert email gets a Room Type column. This is a first step towards new room types with their own tailored inspection questions, which follows in a later app update.
19 Sep 2026
  • LBG - Room CheckerEvery site has now moved to the new database, and the old SharePoint-based tile has been retired. The launcher now shows a single LBG Room Checker tile — this is what was LBG Room Checker v2, simply taking over the original tile's place and name, so nothing changes about how you use it day to day. All rooms, checks, faults and photos from every site have been carried across; the old app's code is kept, unreachable, in case it's ever needed again.
  • LBG - Site ManagementNew, managers only: a Recipients tab lists who receives each automatic e-mail — the daily, weekly and monthly reports, fault alerts, and the overdue-room digest — replacing the SharePoint lists that used to control this. Add an address, pause one without losing it, or remove one added in error, all from the browser.
  • LBG - Site ManagementRoom details: a room's check frequency can now be edited from its detail panel, the same options the Import tab already offers when creating a room. A room with no frequency ever recorded now correctly shows Never instead of Not set.
  • LBG - Site ManagementNew option for check frequency: Never — for a site on a "next day fix" support contract rather than a regular inspection schedule, so that room is never wrongly flagged as overdue. The Overview page now has a Never checked section at the bottom listing every room set this way, since such a room deliberately doesn't show up anywhere else on the page (it's never counted as overdue, by design).
18 Sep 2026
  • LBG - Site ManagementEvery site's coverage information, who owns each building and which days they cover, now comes from the same Dataverse database the newer sites already use, instead of the old SharePoint list. Nothing changes on screen; this is what runs behind it.
  • LBG - Room CheckerFixed: the app could fail to open at all. A recent update to Apple's own build tools meant the app could close itself immediately on opening, before showing anything. If you saw that happen, please update to the latest version; it now opens normally again.

  • LBG - Site ManagementImport tab: a room at a site the database does not have yet can now be created from the preview. Reverted fields are struck through and marked, a field that had changed since the import says so, a failed revert says why and keeps the button, and the Undo button goes once everything is done. The history stays on screen; a room the import created is never deleted by Undo.

A camera firmware such as Poly Studio, Meet Up, Brio or Logitech Rally only looks at camera slots, and a touch-panel firmware only at touch-panel slots, so a room with a Poly camera and a Poly touch controller no longer reports "2 Poly-vendor slots found". On the current export that turns 79 undecided rooms into attributed ones with none left ambiguous. The list shows the row's own building first, headed with the building and the city, "Show all" widens to the whole city with a way back, and a building with no rooms in the database yet says so instead of silently listing the city.

  • LBG - Site ManagementImport tab: the portal exports Lenovo and Intel PC models as hardware codes; the import now translates them to the list's product names, 11RVS02701 to "ThinkSmart Core Device for Poly", 10T1S02201 to "M920q Desktop (ThinkCentre)", 11RXS0240E to "ThinkSmart Core Device for Logitech" and NUC8BEB to "Intel NUC", noting the code the export sent. A code not on that list is still refused rather than guessed.
  • LBG - Site ManagementImport tab, fixed: a PC make or model that matches the list apart from capitals or spacing, such as "Dell Inc." against the list's "DELL Inc.", is now accepted and written with the list's spelling, on updates and on new rooms, with a note showing what the export said. Under the "Choose a room" list, "Create as new room" (off by default) shows what would be created for checking: the portal's name, the room ID in the estate's style, site and building from the group, the room type, a best-guess floor marked for checking, the PC details, and a fortnightly check frequency. It refuses a name the database already holds, a name that appears twice in the file, or two rows that would share a room ID, and it flags a building the site does not have yet. A site the database does not have yet was refused at first; see the later entry above. Undo does not delete a created room. A created row shows "Created as …" and cannot be created twice.

A room is found by name first, ignoring capitals, dashes and spacing (the database mostly holds names in capitals, which is why most of an export came back "unmatched"), then by device: a room with the same hostname or serial number is matched automatically and shown as a pre-selected pick you can change. Anything still unmatched on a site the database knows gets a "Choose a room" list of that site's rooms, same building first, with a search box that also finds a room by its hostname or serial. Sites that have moved to Dataverse, or are not in the database yet, stay unmatched as before. Nothing is renamed.

Rooms now have a PC Serial Number field on both databases; the import writes Hostname to the hostname and Device Serial Number to the serial, both exactly as exported (a Surface Hub keeps its 12 digits). The room report's serial column shows the real serial, blank until an import or an equipment edit fills it, and the equipment editor shows and edits it next to the hostname. An .xlsx that has lost a hub serial's leading zeros (Excel turns 000391122462 into a number) is refused with a clear note rather than imported truncated.
  • LBG - Site ManagementImport tab: the preview now shows the whole picture before you apply. Each matched room also lists the fields the spreadsheet and the room already agree on, marked (unchanged) with no tick, and a Show all N spreadsheet values link opens every filled cell of that row so it can be checked against the room. Ticks per change and per room work as before.
